# Preset verification

Checked against public vendor API references. The 2026-11-10 batches cover fetch-incidents, threat-intel reputation, ITSM and IAM, EDR or cloud response actions, and Palo Alto Networks products plus SIEM and network gear. PAN-OS now includes commit and job polling. WildFire v2 adds the XML report and URL submit. Cortex XDR IR adds isolate and unisolate. QRadar offenses and Ariel, SplunkPy search export, Elasticsearch v2, Sumo Logic Cloud SIEM, Zscaler Internet Access, Cortex Data Lake, and Prisma Cloud stay on their earlier presets. EC2, IAM, STS, and SQS fetch return query-protocol XML (Action=, namespace, and RequestId). STS AssumeRole and SQS ReceiveMessage and DeleteMessage are included so an assumed role can call the queue. Signature checks stay off until enabled. Notes say when a vendor page was login-gated or not reloaded. Those shapes use the public client in demisto/content and, when one exists, the integration test fixture. The other catalog entries stay inferred and are not marked verified.
