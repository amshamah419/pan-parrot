# Preset verification

Checked against public vendor API references on 2026-11-09. The other catalog entries stay inferred from demisto/content samples and are not marked verified.

| Preset | Status | Doc | Notes |
| --- | --- | --- | --- |
| Akamai WAF SIEM | verified | https://techdocs.akamai.com/siem-integration/reference/get-config | Akamai's default limit is 10000 and the documented maximum is 600000. This mock returns at most 500 events and 2 MB per call, then an offset. If from and offset are both present, Akamai uses time mode. This mock does the same. Production offset tokens are long opaque strings. This mock uses a shorter pp_ token that still round-trips. botData, clientData, and userRiskData are omitted. httpMessage.query is included because the public event schema requires it. Akamai 429 bodies are application/problem+json. Chaos errors here are a small JSON object, with Retry-After on 429 and 503. |
| Atlassian Jira v3 | verified | https://developer.atlassian.com/cloud/jira/platform/rest/v3/api-group-issue-search/ | XSOAR calls GET /rest/api/3/search/jql and reads issues plus nextPageToken. The older GET /rest/api/3/search is also mocked. Issue fields are a subset of the official issue schema. names and renderedFields are omitted. |
| Cisco Umbrella Reporting | verified | https://developer.cisco.com/docs/cloud-security/umbrella-api-api-reference-reports-reporting-api-activity-get-activity-dns/ | from, to, and limit are required by Cisco. This mock still answers if they are omitted. A real deployment may 302 to a regional reports host. This mock returns 200 directly. OAuth is not checked. |
| CrowdStrike Falcon | verified | https://developer.crowdstrike.com/api-reference/collections/alerts/ | CrowdStrike's public docs mark the Detects collection deprecated and decommissioned on 2025-09-30. XSOAR's client still calls /detects/queries/detects/v1 in older tests, so those paths are mocked too. Query endpoints return resource ids inside meta.pagination. Entity endpoints are POST and return alert objects. This mock does not check the OAuth token. Falcon's documented query limit can be far above this mock's 500-record page cap. |
| G Suite Security Alert Center | verified | https://developers.google.com/workspace/admin/alertcenter/reference/rest/v1beta1/alerts/list | pageSize and pageToken match the Alert Center list method. An empty nextPageToken means the last page. Alert data payloads differ by source. This mock includes the common alert fields and a short data object. |
| Microsoft 365 Defender | verified | https://learn.microsoft.com/en-us/microsoft-365/security/defender/api-list-incidents | The incidents list is { value: [...] }. nextLink is included while pages remain. Alerts nested on an incident are shortened. |
| Microsoft Graph Security | verified | https://learn.microsoft.com/en-us/graph/api/security-list-alerts_v2?view=graph-rest-1.0 | Microsoft Graph pages with @odata.nextLink. This mock also honors $top and $skip. The real API may omit @odata.nextLink when a page happens to contain everything. That is not simulated unless you stop before the virtual catalog ends. Bearer tokens are not checked. |
| Microsoft Sentinel | verified | https://learn.microsoft.com/en-us/rest/api/securityinsights/incidents/list?view=rest-securityinsights-2024-03-01 | Point the integration server URL at the catch URL plus the workspace path ending in Microsoft.SecurityInsights. The client appends incidents and api-version=2024-03-01. Pages use nextLink. $top is honored up to 500. Azure's documented maximum for $top is 1000. Arm authorization is not checked. |
| Mimecast v2 | sample | https://integrations.mimecast.com/documentation/endpoint-reference/logs-and-statistics/get-siem-logs/ | POST /api/audit/get-siem-logs returns an octet-stream log or a zip, plus an mc-siem-token header. A JSON body means there are no further logs. The XSOAR event collector only accepts the zip. The inferred JSON sample was left in place. |
| Okta v2 | verified | https://developer.okta.com/docs/api/openapi/okta-management/management/tags/systemlog/other/listlogevents | Official limit is 0–1000 and defaults to 100. This mock still caps a page at 500 records and 2 MB. Polling requests (no until, sortOrder ASCENDING) always include rel=next even when the page is empty. Set pagination glitch to endless to simulate that. since and after are mutually exclusive in the real API. This mock accepts both and uses after as the page token. |
| Palo Alto Networks PAN-OS | sample | https://docs.paloaltonetworks.com/ngfw/api/pan-os | PAN-OS and Panorama operational commands return XML from /api. The inferred preset is JSON from a test fixture and was not marked verified. |
| Palo Alto Networks WildFire v2 | sample | https://docs.paloaltonetworks.com/wildfire/u-v/wildfire-api/get-wildfire-information-through-the-wildfire-api/get-a-wildfire-verdict-wildfire-api | POST /publicapi/get/verdict returns XML, with verdict codes 0, 1, 2, 4, 5, and negative pending codes. This mocker emits JSON, so the preset was left as a sample. |
| Proofpoint TAP v2 | verified | https://help.proofpoint.com/Threat_Insight_Dashboard/API_Documentation/SIEM_API | Proofpoint's SIEM API is /v2/siem/clicks and /v2/siem/messages with an interval query such as PT1H. The body is not a generic offset list. clicksBlocked and clicksPermitted are both generated from the same click shape. |
| ServiceNow v2 | verified | https://www.servicenow.com/docs/r/api-reference/rest-apis/c_TableAPI.html | ServiceNow pages with sysparm_limit and sysparm_offset and returns X-Total-Count. Those headers are set. Link headers are not. Only the incident table shape is modeled. Other table names still match {table} and return the same incident-shaped rows. |
| Slack v3 | verified | https://docs.slack.dev/reference/methods/conversations.history | Slack's method is GET conversations.history with channel and cursor. This mock also accepts the path with a leading slash. ok is always true unless chaos errors are enabled. Slack returns ok:false with an error string for bad tokens. That error shape is not the default. |
| SplunkPy | verified | https://help.splunk.com/en/splunk-enterprise/leverage-rest-apis/rest-api-tutorials/10.2/rest-api-tutorials/creating-searches-using-the-rest-api | Creating a job at POST /services/search/jobs returns XML by default. This mock returns JSON { sid } as if output_mode=json was set. POST /services/search/jobs/export returns one JSON object per line with a result field. That matches the export reader the XSOAR pack uses for oneshot search. Splunk authentication and the management port are not checked. |
| VirusTotal (API v3) | verified | https://docs.virustotal.com/reference/file-info | Set the integration base URL to the catch URL. XSOAR appends files/{id}, which replaces https://www.virustotal.com/api/v3. Relationship links and the analysis stats object are shortened. last_analysis_stats counts are examples, not a live engine vote. x-api-key is not required. |
| Zscaler Internet Access | verified | https://help.zscaler.com/zia/url-lookup | The public lookup response is a JSON array of url, urlClassifications, and urlClassificationsWithSecurityAlert. The request body of URLs is not echoed back; each row uses a sample URL. Session cookies and the obfuscated API key are not checked. |
